## 👋 About Me

I single-handedly built and operate a production field-service SaaS platform and warehouse management system that run a real operations company end to end — dispatch, work orders, inventory, invoicing, and AI-assisted scheduling — with live integrations into QuickBooks, Autotask, and ServiceNow.

## ⚡ What I Build

- 🛠️ **Service Manager V2.1** — full service-management platform: dispatch, work orders, invoicing, customer portal
- 📦 **WMS v1** — warehouse management system linked live to the service layer
- 🤖 **AI-powered scheduling** — LLM-assisted field-service dispatch, built as native code pages
- 🔌 **Integrations everywhere** — QuickBooks, Autotask, ServiceNow, Datto RMM, Hudu, self-hosted MCP gateway
